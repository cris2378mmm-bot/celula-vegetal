¿Dónde guardar y abrir este código?

No necesitas instalar nada ni saber programar.

1

Copia todo el código: Guarda el contenido completo en un archivo nuevo en tu computadora llamado index.html (o dale al botón "Preview" arriba a la derecha de esta ventana si estás en Canvas).

2

Doble clic al archivo: Haz doble clic sobre index.html y se abrirá al instante en Chrome, Safari, Edge o Firefox listo para usarse.

3

Para tu entrega escolar: Puedes comprimir ese único archivo index.html en un .ZIP o subirlo gratis a GitHub Pages, Vercel o Netlify para compartir el link con tu profesor.
